从零部署 ​

本教程面向第一次使用 Linux、Git 和 Docker 的用户。最终会在一台服务器上从 GitHub 克隆源码，显式执行 docker build，再通过 Docker Compose 启动服务。

1. 准备服务器 ​

建议使用 64 位 Ubuntu 22.04 或 24.04，至少 1 核 CPU、1 GB 内存和 5 GB 可用磁盘。服务器需要能访问 GitHub、PyPI 和 NotebookLM。

先登录服务器：

bash
ssh <服务器用户名>@<服务器IP>

安装 Git、curl 和证书：

bash
sudo apt update
sudo apt install -y git curl ca-certificates

2. 安装 Docker Engine 与 Compose ​

如果下面两个命令都有版本输出，可跳到下一节：

bash
docker --version
docker compose version

Ubuntu 推荐使用 Docker 官方 APT 仓库。完整说明以 Docker Engine 官方 Ubuntu 安装文档 为准：

bash
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

sudo tee /etc/apt/sources.list.d/docker.sources >/dev/null <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker

验证安装：

bash
sudo docker version
sudo docker compose version

下面所有 Docker 命令都使用 sudo。如果你已经按 Docker 官方 post-install 教程配置当前用户访问 Docker，可自行去掉 sudo。

3. 克隆项目 ​

选择一个部署目录，例如 /opt：

bash
cd /opt
sudo git clone https://github.com/HuFakai/notebooklm-gateway.git
sudo chown -R "$USER":"$USER" notebooklm-gateway
cd notebooklm-gateway

确认当前代码来自 main：

bash
git branch --show-current
git log -1 --oneline

第一个命令应输出 main。

4. 创建环境配置 ​

复制模板：

bash
cp .env.example .env

生成管理 Token：

bash
python3 -c 'import secrets; print(secrets.token_urlsafe(48))'

编辑配置：

bash
nano .env

把生成值完整填入：

dotenv
GATEWAY_PORT=18388
GATEWAY_ADMIN_TOKEN=这里替换为刚才生成的长随机字符串
GATEWAY_CORS_ORIGINS=
GATEWAY_MAX_CLIENTS=20
GATEWAY_CLIENT_IDLE_SECONDS=1800
GATEWAY_KEEPALIVE_SECONDS=600
GATEWAY_MAX_UPLOAD_BYTES=104857600

保存 Nano：按 Ctrl+O、回车，再按 Ctrl+X。管理 Token 至少需要 32 字节，不要使用示例文本。

5. 创建数据目录 ​

bash
mkdir -p data
chmod 700 data

SQLite 的 API Key 和 NotebookLM Cookie Storage State 是明文。不要公开、同步或提交 data/；生产环境应只允许部署用户和容器访问。

6. 构建 Docker 镜像 ​

必须在包含 Dockerfile 的项目根目录运行：

bash
sudo docker build --pull -t notebooklm-gateway:latest .

命令最后出现 Successfully tagged 或 BuildKit 的成功提示即表示完成。查看镜像：

bash
sudo docker image ls notebooklm-gateway

7. 启动服务 ​

bash
sudo docker compose up -d --no-build

--no-build 确保 Compose 使用上一步已经构建好的镜像。查看容器：

bash
sudo docker compose ps

正常情况下 notebooklm-gateway-server 会显示 Up，稍后变成 healthy。

8. 验证服务 ​

bash
curl --fail http://127.0.0.1:18388/healthz

成功响应：

json
{"status":"ok"}

然后访问：

  • NoteWeb：http://<服务器IP>:18388/noteweb/
  • 管理控制台：http://<服务器IP>:18388/admin
  • 交互式 API：http://<服务器IP>:18388/docs

如果打不开，先看日志：

bash
sudo docker compose logs --tail=200 gateway

9. 添加 NotebookLM 账户 ​

在有桌面环境的电脑上运行凭据助手：

bash
git clone https://github.com/HuFakai/notebooklm-gateway.git
cd notebooklm-gateway
python3 -m venv .venv-client
source .venv-client/bin/activate
pip install -e '.[client]'
python gateway_client/app.py

填写网关地址、.env 中的管理 Token、Google 邮箱和为该账户分配的用户 API Key。完成浏览器登录并上传后，即可用该用户 Key 登录 NoteWeb。

10. 常用运维命令 ​

bash
# 状态
sudo docker compose ps

# 持续查看日志，Ctrl+C 退出
sudo docker compose logs -f gateway

# 重启
sudo docker compose restart gateway

# 停止并删除容器，保留源码和 data 目录
sudo docker compose down

# 再次启动
sudo docker compose up -d --no-build

不要把 .env、data/ 或凭据文件提交到 Git。
