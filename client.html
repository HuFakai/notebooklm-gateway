桌面凭据助手 ​

桌面凭据助手用于在本机完成 Google/NotebookLM 浏览器登录，然后把 Cookie Storage State 上传到远程网关。本页以 macOS 为主，命令同样适用于大多数 Linux 桌面。

macOS 首次安装 ​

先进入项目目录并确认 python3 可用：

bash
cd /Users/<你的用户名>/Documents/project/notebooklm
command -v python3
python3 --version

项目支持 Python 3.11–3.14。macOS 通常只有 python3，没有 python，因此后续命令不要使用 python。

重新创建虚拟环境：

bash
rm -rf .venv-client
python3 -m venv .venv-client

使用官方 PyPI 安装。PIP_CONFIG_FILE=/dev/null 只对当前命令生效，可以绕过用户目录中失效的 pip 镜像配置：

bash
PIP_CONFIG_FILE=/dev/null PIP_INDEX_URL=https://pypi.org/simple \
  .venv-client/bin/python -m pip install --upgrade pip

PIP_CONFIG_FILE=/dev/null PIP_INDEX_URL=https://pypi.org/simple \
  .venv-client/bin/python -m pip install -e '.[client]'

这会安装 PySide6、Playwright、notebooklm-py 和客户端所需依赖。首次下载体积较大，请等待安装完成。

启动助手 ​

不需要执行 source 激活虚拟环境，直接运行：

bash
.venv-client/bin/python gateway_client/app.py

以后启动仍然只需要这一条命令。

助手中填写：

  1. 网关地址，例如 https://note.example.com。
  2. 服务器 .env 中的 GATEWAY_ADMIN_TOKEN。
  3. 当前 Google 账户邮箱。
  4. 为该账户分配的用户 API Key，至少 16 字符。

点击“登录 Google 获取凭据”，在系统 Chrome 中完成登录，然后返回助手上传。

当前 macOS 的已验证命令 ​

Apple Silicon Homebrew 默认 Python 路径通常是 /opt/homebrew/bin/python3。如果 command -v python3 输出该路径，可以明确执行：

bash
rm -rf .venv-client
/opt/homebrew/bin/python3 -m venv .venv-client

PIP_CONFIG_FILE=/dev/null PIP_INDEX_URL=https://pypi.org/simple \
  .venv-client/bin/python -m pip install -e '.[client]'

.venv-client/bin/python gateway_client/app.py

常见错误 ​

zsh: command not found: python ​

虚拟环境没有创建。改用：

bash
python3 -m venv .venv-client

不要继续执行后续命令，直到 .venv-client/bin/python 存在：

bash
test -x .venv-client/bin/python && echo "virtual environment ready"

source: no such file or directory ​

这是上一条创建虚拟环境命令失败造成的连锁错误。本项目不要求激活环境，创建成功后直接使用 .venv-client/bin/python。

CERTIFICATE_VERIFY_FAILED ​

先查看 pip 配置来源：

bash
python3 -m pip config debug

如果输出显示 ~/.pip/pip.conf 配置了无法验证证书的镜像，使用本页提供的 PIP_CONFIG_FILE=/dev/null 与官方 PyPI 命令即可临时绕过，不必删除个人配置。

如果官方 PyPI 仍然证书失败，但 /opt/homebrew/bin/python3 存在，请使用 Homebrew Python 重新创建虚拟环境：

bash
rm -rf .venv-client
/opt/homebrew/bin/python3 -m venv .venv-client

检查依赖是否完整 ​

bash
.venv-client/bin/python -m pip check
.venv-client/bin/python -c 'import PySide6, playwright, notebooklm; print("client dependencies ready")'

两条命令都成功后，再启动助手。
