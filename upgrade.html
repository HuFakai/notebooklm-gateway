重新部署最新版 ​

本教程采用最容易核对的方式：停止并删除当前项目容器，删除服务器上的项目源码，重新从 GitHub 克隆 main，重新构建镜像并启动。它不执行数据库转换，也不要求复用已有 data/。

开始前确认 ​

你需要知道：

  • 服务器 SSH 登录信息。
  • 当前项目目录，例如 /opt/notebooklm-gateway。
  • .env 中使用的管理 Token；如果准备重新配置，也可以生成新的 Token。
  • 已经按自己的需要备份数据。

下面命令假设项目位于 /opt/notebooklm-gateway。路径不同请先替换。

1. 记录当前状态 ​

bash
cd /opt/notebooklm-gateway
sudo docker compose ps
git rev-parse --short HEAD

如果需要保留当前配置，再额外复制 .env 到项目目录之外：

bash
cp .env "$HOME/notebooklm-gateway.env.backup"
chmod 600 "$HOME/notebooklm-gateway.env.backup"

2. 停止并删除项目容器 ​

bash
cd /opt/notebooklm-gateway
sudo docker compose down --remove-orphans

确认项目容器已经消失：

bash
sudo docker ps -a --filter name=notebooklm-gateway-server

如果输出只剩表头，说明容器已经删除。

3. 删除项目镜像和源码 ​

删除项目镜像：

bash
sudo docker image rm notebooklm-gateway:latest || true

返回上级目录并删除源码。执行 rm -rf 前务必用 pwd 和 ls 再确认一次路径：

bash
cd /opt
pwd
ls -la notebooklm-gateway
sudo rm -rf /opt/notebooklm-gateway

该命令会删除项目目录内的 .env 和 data/，所以只能在备份或确认无需保留后执行。

4. 重新克隆 main ​

bash
cd /opt
sudo git clone --branch main --single-branch \
  https://github.com/HuFakai/notebooklm-gateway.git
sudo chown -R "$USER":"$USER" notebooklm-gateway
cd notebooklm-gateway

核对分支和提交：

bash
git branch --show-current
git log -1 --oneline
git status --short

应看到 main，且 git status --short 没有输出。

5. 重新创建配置和空数据目录 ​

bash
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(48))'
nano .env
mkdir -p data
chmod 700 data

把新生成的 Token 写入 GATEWAY_ADMIN_TOKEN。如果继续使用之前备份的配置，可以先复制回来，再逐项对照 .env.example：

bash
cp "$HOME/notebooklm-gateway.env.backup" .env
comm -3 \
  <(sed -n 's/^\([A-Z0-9_]*\)=.*/\1/p' .env.example | sort) \
  <(sed -n 's/^\([A-Z0-9_]*\)=.*/\1/p' .env | sort)

comm 没有输出表示变量名一致，而且不会把 Token 值打印到终端。仍需确认管理 Token 不是示例值。

6. 构建并启动最新版 ​

bash
sudo docker build --pull --no-cache -t notebooklm-gateway:latest .
sudo docker compose up -d --no-build

第一次干净构建需要下载 Python 基础镜像和依赖，请等待命令完成，不要中途关闭 SSH 窗口。

7. 验证 ​

bash
sudo docker compose ps
curl --fail http://127.0.0.1:18388/healthz
sudo docker compose logs --tail=200 gateway

健康检查应返回：

json
{"status":"ok"}

浏览器检查：

  • http://<服务器IP>:18388/admin
  • http://<服务器IP>:18388/noteweb/
  • http://<服务器IP>:18388/docs

这是空数据目录部署，因此需要重新通过凭据助手添加 NotebookLM 账户。

常见问题 ​

GATEWAY_ADMIN_TOKEN 报错 ​

检查 .env 是否存在、变量名是否正确、值是否至少 32 字节：

bash
grep '^GATEWAY_ADMIN_TOKEN=' .env

18388 端口被占用 ​

bash
sudo ss -lntp | grep 18388

结束占用程序，或修改 .env 中的 GATEWAY_PORT 后重新启动。

构建过程中无法下载依赖 ​

检查服务器 DNS、代理以及对 docker.io 和 pypi.org 的访问。网络恢复后重新运行 docker build。

容器反复重启 ​

bash
sudo docker compose ps
sudo docker compose logs --tail=300 gateway

优先检查 .env、目录权限和日志中的第一条异常。
